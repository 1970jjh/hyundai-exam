# DESIGN.md — 신입 온보딩 퀴즈 챌린지 (B안)

GPT 시안 `B-mz.png`를 코드로 옮기기 위한 디자인 명세입니다. 앱의 `app/globals.css`가 이 문서를 구현하고, `design/preview.html`에서 컴포넌트를 한눈에 볼 수 있습니다.

## 1. 무드
- 키워드: **밝고, 말랑하고, 게임 같은**. 파스텔 그라데이션 위에 떠 있는 유리 카드, 3D 클레이 소품, 손글씨 메모와 스티커.
- 학습자(폰)는 "챌린지에 참여한다"는 느낌, 관리자는 같은 톤을 유지하되 정보 밀도가 높은 카드 대시보드.
- 모든 문구는 존댓말 반말 섞인 친근체(예: "1분 남았어요! 서둘러요", "화이팅!").

| 토큰 | 값 | 용도 |

## 3. 타이포
- 본문: **Pretendard** (CDN), 굵기 500/600/700/800.
- 큰 제목: **Black Han Sans**(Google Fonts) — 시안 좌측 "신입 온보딩 퀴즈 챌린지" 같은 두꺼운 디스플레이, 흰 외곽선 + 보라 그림자(`-webkit-text-stroke` 대신 `text-shadow` 4방향).
- 손글씨 메모: **Gaegu**(Google Fonts) 700 — "오늘도 한 문제 더!", "화이팅!" 등 장식 문구.
- 크기: 디스플레이 40–64px / 문제 문장 20–22px 800 / 보기 16–17px 600 / 라벨 13px.

## 4. 형태
- 모서리: 카드 24px, 보기 카드 20px, 버튼 999px(완전 알약), 칩 999px.
- 그림자: `0 12px 40px rgba(123,92,250,.18)`; 떠 있는 소품은 `drop-shadow(0 10px 18px rgba(80,40,160,.25))`.
- 보기 카드: 왼쪽에 둥근 사각 문자 배지(A/B/C/D, 흰 글자, 진한 색 배경), 오른쪽에 체크박스(선택 시 진한 색 + 흰 체크). 살짝(-1°~1°) 기울인 재미는 데스크톱 쇼케이스에서만, 실제 폰에선 수평.
- 스티커 배지: 하트 모양/구름 모양 보라 그라데이션 + 흰 글씨("복수 선택 가능 ✓"), 약간 회전(-8°).
- 메모지: 노란 포스트잇(`#FFF3A8`) 회전 6°, Gaegu 글씨.

## 5. 컴포넌트
1. **상단 바(폰)**: 왼쪽 시험 제목 + 🎉, 오른쪽 알약 칩 = 아바타(이니셜 원) + 이름. 그 아래 진행바(보라, 둥근 12px)와 `2/10 문제`.
2. **링 타이머**: 지름 84px 원형 진행 링(코랄), 가운데 `04:12` 800. 경고 시점부터 링·숫자 깜빡임(`pulse`), 그리고 **경고 토스트**: 코랄 알약, 🕐 아이콘, "1분 남았어요! 서둘러요!" 흰 글씨, 살짝 흔들림(`wiggle`).
3. **문제 카드**: 유리 카드 안에 마스코트 병아리(좌상단 64px) + 카테고리 칩(연보라, "조직 문화") + 문제 문장 + 회색 보조 설명.
4. **보기 4개**: A/B/C/D 파스텔 카드(위 색 토큰).
5. **하단 내비**: 왼쪽 흰 알약 "‹ 이전 문제", 오른쪽 보라 그라데이션 알약 "다음 문제 →"(마지막엔 "제출하기 🚀").
6. **관리자 'AI 문제 만들기' 카드**: ✨ 아이콘 제목 + "Beta" 보라 칩. ① 학습 자료 업로드: 점선 드롭존 + 업로드된 파일 칩(파일 아이콘·이름·용량·✕). ② 문제 유형 4칸 타일(객관식/복수정답/단답형/서술형) — 각 타일에 컬러 아이콘, 문항 수, 슬라이더. 넓은 그라데이션 버튼 "✨ AI로 문제 생성하기 →".
7. **결과 대시보드 카드**: 📊 제목 + 기간 셀렉트. KPI 3~4칸(아이콘 원 + 라벨 + 큰 숫자: 응시자 수 / 평균 점수 🏆 / 표준편차 Σ / 합격률). 도넛(정답률 분포, 중앙 큰 %) + 범례, **TOP 3 포디움**(가운데 1위 높게, 메달 이미지 + 이름 + 점수, 왕관), 점수 분포 곡선(보라 영역 + 평균 점선 라벨).
8. **장식 소품**: 선글라스 별, 보라 종이비행기, 트로피, 왕관, 알람시계 — `design/assets/*.png`(투명 PNG, GPT 이미지 생성). 화면 모서리에 절대 위치로 떠 있고 천천히 위아래로 둥실(`float` 6s).

## 6. 화면별 구성
| 화면 | 구성 |
|---|---|
| 학습자 입장 | 큰 디스플레이 제목 + 히어로 캐릭터(hero-newbie) + 이름/이메일/소속 입력 + "챌린지 입장하기" |
| 대기실 | 마스코트가 둥실, "곧 시작해요! 👀", 입장 인원 카운트, 손글씨 "오늘도 한 문제 더! 🔥" |
| 응시 | 5번 구성 그대로(상단 바·링 타이머·문제 카드·보기·하단 내비) |
| 제출 완료 대기 | 종이비행기 날아감 + "제출 완료! 결과는 시험이 끝나면 공개돼요" |
| 개인 결과 | 큰 점수 링 + 등수/백분위 칩 + 문항 리스트(✅/❌), 틀린 문항 펼치면 내 답/정답/해설, 축하 소품(트로피·왕관) |
| 관리자 홈 | 좌상단 디스플레이 로고 + 시험 카드 목록(상태 칩: 준비/진행 중/종료) + "새 챌린지 만들기" |
| 관리자 출제 | 6번 카드 + 아래 문항 편집 리스트(유리 카드, 유형 칩, 정답 체크) |
| 관리자 진행(프로젝터) | 큰 QR 유리 카드 + 링크 복사 + 실시간 입장/제출 카운터 + 링 타이머 + 연장/전체 종료 버튼 |
| 결과 대시보드 | 7번 카드 + 문항별 정답률 막대 + 변별도 + 응시자 표 + 다운로드·메일 버튼 |

## 7. 모션
- `float`: translateY 0 → -10px, 6s ease-in-out 무한(소품).
- `pop`: 보기 선택 시 scale .96 → 1.02 → 1, 180ms.
- `pulse`: 경고 시 타이머 opacity/scale 1s 무한.
- `wiggle`: 경고 토스트 rotate ±2°, 0.5s 3회.
- `prefers-reduced-motion`이면 모두 끈다.

## 8. 접근성·모바일
- 터치 영역 최소 52px, 보기 카드 전체가 버튼.
- 대비: 파스텔 카드 위 글자는 `--ink`(대비 12:1 이상).
- 폰 기준 폭 375–430px, 관리자는 1280px 기준 반응형(태블릿에서 2열 → 1열).
- 인쇄(PDF) 시 배경 그라데이션·소품 숨기고 흰 바탕 리포트로 전환.
